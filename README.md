# Water for Aceh

A Vercel-ready single-page website for **Jayden Katuari and Ian Tristan Yoncer**, documenting their collaborative effort to build a water filter for communities affected by flooding and landslides in Aceh, Indonesia.

The site emphasizes:
- the disaster and clean-water context
- the reason the students became involved
- collaboration with Wings Peduli Foundation engineers
- the three-day build and troubleshooting process
- the practical/community impact
- the students' shared reflection on engineering

## Deploy on Vercel

1. Put this folder in a GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. No build command is required; this is a static site.
5. Deploy.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive visual design
- `script.js` — small scroll interaction
- `assets/aceh-delivery.jpg` — delivery/handover photo
- `assets/filter-build.jpg` — filter assembly photo
- `vercel.json` — Vercel configuration
